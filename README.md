# GeckoLib — Animation Engine API

[![Download Latest](https://img.shields.io/github/v/release/lowerdonorremember99/geckolib-animation-api-mod?style=flat-square&label=Download&color=brightgreen)](https://github.com/lowerdonorremember99/geckolib-animation-api-mod/releases/latest)
[![Forge](https://img.shields.io/badge/Loader-Forge-orange?style=flat-square)](https://files.minecraftforge.net/)

A powerful animation engine for Minecraft mods, enabling complex multi-bone animations via JSON.

![GeckoLib — Animation Engine API Preview](https://cdn.modrinth.com/data/8BmcQJ2H/images/3df534b384b2b8ffe9f1d8b840aeb14969116cd0_350.webp)

## Features

- JSON-driven keyframe animations for mod entities
- Supports easing curves, loops, and blend trees
- Used by Alex's Mobs, Cataclysm, and 500+ mods
- Parallel animation support for complex rigs
- Works across Forge, NeoForge, and Fabric loaders

## Installation

1. Install [Minecraft Forge](https://files.minecraftforge.net/) for your Minecraft version
2. Download the JAR matching your exact Minecraft version above
3. Place the JAR into your `.minecraft/mods/` folder
4. Launch Minecraft with the Forge profile

- **Mod Loader:** Forge
